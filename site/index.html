Nijatva Video Player

Ek simple, fast video player — Windows, macOS, Linux, Android aur browser ke liye. Ek hi codebase se bana, green–blue theme ke saath.

Download for Windows .msi · 62 MB Browser me chalao

Saare platforms

Desktop ke liye VLC install hona chahiye — desktop build libVLC use karta hai. Windows par installer unsigned hai, to "More info → Run anyway" karna pad sakta hai. iOS abhi nahi hai (Apple signing certificate chahiye).

Features

Folder library

Videos folder-wise, real thumbnails aur duration ke saath.

Gestures

Left swipe brightness, right swipe volume, horizontal seek, pinch zoom.

Background & PiP

Screen off hone par bhi chalta hai; picture-in-picture bhi.

Subtitles & audio

Track switching, subtitle size, sidecar .srt auto-load.

Playlists, vault, app lock

Playlists banao, private videos vault me rakho, PIN se lock karo.

Network & YouTube

Stream URL, ad/tracker blocking, downloads, YouTube links in-app.
